# FOX - All-in-One Discord Bot

**FOX** is an all-in-one Discord bot made by **Devil Fox**.

> Moderation, utility, automation, security, music, fun, and server-management tools in one bot.

## Features

- Moderation and permission management
- Welcome and auto-role systems
- Logging and automation
- Giveaway and fun commands
- Utility and server information commands
- Music support through Lavalink
- MongoDB support
- Configurable per-server prefix

## Requirements

- Node.js 25
- npm
- A Discord application and bot token
- MongoDB connection string (if database features are enabled)

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/foxbotbydevilfox/FOX-BOT.git
   cd FOX-BOT
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Create a `.env` file in the project root and add your required environment variables.

4. Start the bot:

   ```bash
   npm start
   ```

## Security

Never upload your real bot token, API keys, database credentials, or other secrets to GitHub. Keep them in `.env` and add `.env` to `.gitignore`.
